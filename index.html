About Me

你好，我是 牟盛昊

一名在校大学生，正在系统学习 Web 前端开发，喜欢把想法用浏览器里的像素和动画表达出来。

我是一名普通但在努力的大学生。从 HTML 结构、CSS 布局到 JavaScript 交互，我一路把课本上的知识点变成了一个个能在浏览器里点得动、看得见的页面。

我着迷于「写几行代码，界面就活起来」这件事——一个渐变色、一次过渡动画、一段顺滑的滚动，都能让我反复调试很久并乐在其中。

现在这份主页就是我 Web 前端技术课程的一次实践作业：从配色方案、栅格布局到交互动效，全部手写完成，没有使用任何前端框架。

下一步，我想深入 响应式布局、CSS 动画与组件化思维，把页面做得既好看又好用。

Journey

我的 学习历程

从第一次打出 <h1> 到现在，一步步走过来的路。

第一阶段

敲开网页的门

认识标签、写第一个 HTML 页面，第一次在浏览器里看到自己的文字被渲染出来，那种感觉挺奇妙。

第二阶段

沉迷于布局与配色

被 CSS 折磨也被 CSS 治愈。学会了盒模型、Flex 布局和渐变色，开始给页面「化妆」。

第三阶段

让页面动起来

接触 JavaScript，用 DOM 操作和事件监听做出下拉菜单、轮播图，页面终于能响应我的操作了。

现在

完成这份课程作业

把学到的知识点整合成一个完整的个人主页：多色渐变、玻璃卡片、滚动动效，全部手写、零框架。
